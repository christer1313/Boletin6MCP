# Boletin6MCP

Repositorio organizado por ejercicios, con una carpeta y un `README.md` por ejercicio para reproducir la practica completa.

## Estructura de entrega

```text
Boletin6-GAC/
├── Ej1-MCPServers/
│   └── README.md
├── Ej2-Copilot-MCP/
│   └── README.md
└── Ej3-MCPServers/
	 └── README.md
```

## Ejercicios

1. `Boletin6-GAC/Ej1-MCPServers`
	- Servidores MCP SQL y NoSQL contenerizados.

2. `Boletin6-GAC/Ej2-Copilot-MCP`
	- Integracion de los servidores MCP con GitHub Copilot Chat.

3. `Boletin6-GAC/Ej3-MCPServers`
	- Adaptacion de agentes `smolagents` para consumir herramientas MCP mediante `MCPClient`.
	- Adaptacion equivalente con `LangChain/LangGraph` para consumir las mismas herramientas MCP.

También falta el ejercicio opcional, aunque para la aplicación de mi TFM y de mi trabajo
en el CDL uno de los objetivos es implementar un chatbot como un asistente, y usaré estas tecnologías.

Cada carpeta incluye pasos de preparacion, ejecucion y validacion.
